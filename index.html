JuryRoll v1

Match juror records (disqualified as non-citizen) to a voter roll. Make a referral list for election officials.

All processing occurs in this browser. No data leaves this computer. This page has no network connections. It uses no external scripts and sends no data. The page security policy blocks all network requests. You can disconnect from the internet before you load your files.

Read this first: limits of a match

  • A match is a lead. It is not proof that a person is not a citizen.
  • Some people state that they are not citizens to avoid jury duty. Their jury record is then false.
  • Some people become citizens after they complete the jury questionnaire. The jury record can be old.
  • Different people can have the same name and the same date of birth (DOB).
  • Only election officials can verify citizenship. For example, they can use the federal SAVE system (USCIS).
  • Federal law sets a deadline. Under the National Voter Registration Act, 52 U.S.C. 20507(c)(2)(A), a state must complete a systematic removal program not later than 90 days before a federal primary or general election. For the general election on Nov 3, 2026, that date was Aug 5, 2026.
  • A federal court applied this rule to a program that matched records to find non-citizens: Arcia v. Florida Secretary of State, 772 F.3d 1335 (11th Cir. 2014). The court also said that the rule does not stop removals based on individual information.
  • State laws about the use of voter-file data are different in each state. Some states permit use only for election or political purposes. Jury records can also be confidential. Read your state law before you use these files.
  • Send referrals to your county board of elections. Do not publish names.

Step 4. Results

How the tiers work
Strong
Last name, first name, and full DOB agree.
Probable
Last name, first initial, and full DOB agree. Or: last name, first name, birth year, and street address agree (used only when one file has no full DOB).
Weak
Only last name and first name agree. The DOB is missing or different. Weak matches are hidden and are not exported unless you select them.
Lower tier
If both files show a middle initial or a suffix (Jr, Sr, III) and the values are different, the tool moves the match down one tier.
Normalization
The tool ignores case, accents, punctuation, spaces, and hyphens in names. It removes suffixes from name fields. It reads many DOB formats. It does not match nicknames (Bill / William) or spelling errors.
Caution: weak matches. Only the name agrees. Most weak matches are different people with the same name. Do not refer a weak match without more evidence.

Referral for official verification

Each row is a lead for an election official to verify. It is not a removal list. It is not a list of persons who voted illegally.
