### 6.14 Arkansas

When a court finds a juror is not a citizen, the clerk notes it in the jury book and tells the county registrar. The registrar cancels the registration (Ark. Const. amend. 51, sec. 11(e)).
The master juror list is not open to the public (Ark. Code 16-32-103(e)(2)). Disclosure of juror information is restricted by law (Ark. Code 16-32-111). Do not ask for jury-book entries. JuryRoll refuses any Arkansas jury list.
The state voter file has a date of birth. This does not make matching possible, because the jury list is refused first.
Arkansas allows challenges only at the polls. JuryRoll gives no challenge guidance.
Ask the county clerk for counts by month: clerk notices received and non-citizen cancellations. Also read the State Board of Election Commissioners' annual audit report. The Arkansas FOIA covers Arkansas citizens only. Ask for counts only.
